### Deskripsi Proyek
Proyek ini merupakan rancangan program sederhana menggunakan Python untuk membantu mengolah nilai matematika siswa. Program dirancang untuk menghitung rata-rata, nilai tertinggi, nilai terendah, serta jumlah siswa yang mencapai dan belum mencapai Kriteria Ketuntasan Minimal (KKM).

### Tujuan
1. Mempermudah pengolahan nilai matematika siswa.
2. Mengurangi kesalahan dalam perhitungan manual.
3. Menampilkan hasil analisis nilai secara teratur.
4. Menerapkan materi algoritma dan pemrograman Python.

### Teknologi yang Digunakan
- Python
- Visual Studio Code
- Git
- GitHub

### Rancangan Fitur
- Membaca data nama dan nilai siswa.
- Memeriksa validitas nilai.
- Menghitung rata-rata nilai kelas.
- Menentukan nilai tertinggi dan terendah.
- Menghitung jumlah siswa yang mencapai KKM.
- Menampilkan dan menyimpan hasil analisis.

### Rencana Pengujian
Pengujian dirancang untuk memeriksa data normal, nilai batas bawah, nilai batas atas, nilai tidak valid, file yang tidak ditemukan, dan kondisi seluruh siswa mencapai KKM.
